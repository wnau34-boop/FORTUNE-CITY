📘 วิธีเล่น Fortune City

Fortune City คือ Strategic Property Board Game เป้าหมายไม่ใช่แค่เดินให้ไกล แต่คือการซื้อ Property ที่เหมาะสม สร้าง Set คุม District ใช้ Focus และ Skill ให้ถูกจังหวะ แล้วจบเกมด้วย Net Worth สูงที่สุด

⭐ เกมแรกแนะนำ

15 รอบ • Normal AI • Sunrise City
15 รอบคือ Standard Game ที่เกมถูก Balance ไว้เต็มรูปแบบและได้รับ EXP 100% เลือก Skill ที่ใช้ได้ตั้งแต่ Lv.1 ก่อน เช่น Quick Step + Rent Shield หรือ Quick Step + Focus Reserve

🚀 Quick Start — 5 ขั้นตอน

1
เตรียม Loadoutเลือก Skill 2 ช่องรวมไม่เกิน 6 SP และ Career Card 1 ใบ แล้วเลือกจำนวนรอบกับระดับ AI
2
ทอยเต๋าและเลือกทางเดินตามแต้มเต๋า บาง Map มี Junction ให้เลือกเส้นทาง ใช้ Focus เพื่อควบคุมตำแหน่งได้
3
ซื้อ Propertyถ้าลง Property ที่ไม่มีเจ้าของ สามารถซื้อได้ หรือปล่อยเข้า Auction ตามสถานการณ์
4
สร้าง Set / Districtถือ Property ใน Set เดียวกันเพื่อเพิ่ม Synergy และคุม District เพื่อรับสิทธิ์ Upgrade ถูกลง
5
ชนะด้วย Net Worthเมื่อครบจำนวนรอบ ระบบจัดอันดับจาก Cash + มูลค่า Property + มูลค่า Upgrade + Full Set Bonus + District Control Bonus ผู้ที่ Net Worth สูงสุดชนะ

🏙 ระบบสำคัญที่ควรรู้

🏠
Property

เป็นแกนหลักของเกม ซื้อ Property เพื่อเก็บค่าเช่าและสร้างมูลค่ารวมของคุณ อย่าใช้เงินหมดจนไม่มีสำรองสำหรับจังหวะสำคัญ

🧩
Set Synergy

ถือ 2/3 ใน Set ได้ Rent +15% และ Full Set 3/3 ได้ Rent +30% บาง Set มี Ability เพิ่มเติม เช่น Mobility Full Set ช่วย Recharge Focus

👑
District Control

ผู้ที่ถือ Property เด่นที่สุดใน District จะเป็น Leader และได้รับส่วนลด Upgrade ภายใน District นั้น

⬆️
Upgrade

ลงทุนเพิ่มกับ Property เดิมเพื่อเพิ่ม Rent ต้องเลือกระหว่างขยาย Portfolio กับพัฒนา Property ที่มีอยู่

🎯
Focus

ทรัพยากรสำหรับควบคุมผล Movement เช่นปรับตำแหน่งหรือ Reroll เพื่อช่วยให้ลง Property, Junction หรือ Tile สำคัญที่ต้องการได้แม่นขึ้น

🧠
Skill Loadout

Character ไม่มี Skill Bonus โดยตรง ผู้เล่นจัด Skill 2 ช่องเองภายในงบ 6 SP แต่ละ Skill Slot ใช้ได้หนึ่งครั้งต่อเกม

💼
Career Card

Equip ได้ 1 ใบเพื่อรับ Passive Advantage เล็กน้อย เช่น Token เริ่มต้น, ส่วนลด Upgrade แรก หรือข้อมูล Forecast เพิ่ม Career มีผลน้อยกว่า Skill อย่างชัดเจน

🤝
Trade Center

เมื่อเข้า Trade Hub สามารถซื้อหรือ Swap Property กับ AI ได้ แต่ AI จะป้องกัน Core Asset และต้องเหลือเงินสำรองหลังดีล

🔨
Auction

Property ที่ไม่ได้ซื้อโดยตรงยังอาจถูกนำเข้าประมูล จึงมีโอกาสได้ Property ต่ำกว่าหรือสูงกว่า Base Price ตามการแข่งขัน

📈
City Market

Market Effect เกิดเป็นช่วง ๆ และมี Forecast ล่วงหน้า ใช้ข้อมูลนี้วางแผนซื้อ Upgrade หรือเน้น Property ประเภทที่กำลังได้ Bonus

🎴
Tactic Hub

แต่ละ Map มี Tactic Hub 1 ช่อง เมื่อลงช่องนี้จะสุ่ม Tactic Card 1 ใบ เช่น ถอยหลัง, ย้ายตำแหน่ง, สลับตำแหน่ง หรือปิด Focus จากนั้นกดใช้การ์ดและเลือกคู่แข่งเป็นเป้าหมาย ผู้ที่เพิ่งโดนจะได้รับ Tactic Protection จนจบเทิร์นถัดไปเพื่อป้องกันการโดนรุมซ้ำ

🎒
Home Bag

Item ที่สะสมจาก Shop, Tactic Tile และรางวัลจะรวมไว้ใน Bag หน้า Home แยก Consumable / Tactic Card และพกเข้า Match ถัดไปอัตโนมัติ

📦
Fortune Chests

เล่นจบ Match เพื่อรับ Chest มี 3 Slots และเปิดได้พร้อมกัน 1 กล่อง • Reward หลักเป็น Consumable/Shard และมีโอกาสปลด Skill หรือ Career ใหม่ • Chest ไม่ขายด้วยเงินจริง

🌙 Moonlight BayCanal / Mobility • ลง Transport Property ของตัวเองรับ Focus +1 • 🌑 Abyss Whirlpool เป็น Satan Zone • 🌫️ Fog Route เป็น Hazard แยกต่างหาก
